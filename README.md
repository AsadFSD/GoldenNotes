# 📝 GoldenNotes Studio

A modern, AI-powered note-taking application designed for knowledge workers. GoldenNotes combines beautiful design, smart features, and powerful markdown editing to help you capture, organize, and connect your ideas.

**Version:** 2.0 | **Built:** May 2026

---

## ✨ Core Features

### 🎨 **Multiple Curated Themes**
Choose from professionally designed themes:
- Warm Minimalism (cozy, minimal aesthetic)
- Liquid Glass (modern, glassmorphic UI)
- Notes App Chic (clean, Apple Notes-inspired)
- Custom theme support for personalization

### ✍️ **Full Markdown Editor**
- Complete markdown syntax support
- Live preview (split view)
- Distraction-free focus mode
- Syntax highlighting for code blocks
- Support for tables, lists, blockquotes
- Keyboard shortcuts for common formatting

### 📊 **Interactive Knowledge Graph**
- Visualize note connections in real-time
- Bi-directional linking with `[[Note Title]]` syntax
- Click nodes to edit notes directly from the graph
- See relationships and knowledge networks
- Hover nodes to reveal linked connections

### 🤖 **AI Assistant**
- **Summarize** – Generate concise summaries of long notes
- **Fix Grammar** – Auto-correct spelling and grammar issues
- **Generate Templates** – Quick project/meeting templates
- Inline suggestions based on note content

### 🏷️ **Smart Organization**
- Auto-categorization of notes
- Smart tag suggestions based on content
- Advanced search by title, content, tags, and categories
- Saved search views for quick access
- Pin & Favorite system for priority notes

### 📱 **Responsive Design**
- Seamless experience on desktop, tablet, and mobile
- Touch-friendly interface
- Adaptive layouts for all screen sizes
- Fast performance with optimized rendering

### 🎯 **Rich Content Blocks**
- Slash commands (`/`) for quick block insertion
- Checklists for task management
- Code blocks with syntax highlighting
- Quote blocks for inspiration
- Table support for structured data
- Image embedding and preview

### 📤 **Export & Sharing**
- Export notes to Markdown format
- Shareable links with unique identifiers
- Batch export for multiple notes
- Download as JSON for backup

### 💾 **Smart Persistence**
- LocalStorage persistence with automatic saving
- Complete backup of all notes and settings
- Theme preferences saved across sessions
- Recoverable note history
